# Projeto de Análise de Sentimentos com Azure Language Studio

## Descrição
Este projeto demonstra como realizar a análise de sentimentos em um conjunto de sentenças utilizando o Azure Language Studio.

## Passos
1. Criação de um repositório no GitHub
2. Criação da pasta `inputs` e adição de um arquivo de texto com sentenças
3. Utilização do Azure Language Studio para análise das sentenças
4. Documentação do processo e insights no README.md

## Processo
O arquivo de texto contém algumas sentenças que representam avaliações de serviços e produtos. As sentenças foram analisadas utilizando o serviço de **Análise de Sentimentos** do Azure, onde cada sentença foi classificada como positiva, negativa ou neutra.

## Insights
- O serviço de Análise de Sentimentos do Azure foi capaz de classificar as sentenças com bastante precisão.
- Possibilidade de utilizar esse modelo para automatizar a análise de feedbacks de clientes, aumentando a eficiência na interpretação de opiniões em grande escala.
